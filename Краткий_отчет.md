# Краткий отчёт по практической работе №5

## Тема
Технический UI Kit для Help Desk: дизайн-токены, темы, состояния компонентов и плотность интерфейса.

## Что было реализовано

### 1. Токены
- сохранена исходная схема из трёх уровней: primitive → semantic → component;
- добавлены семантические значения для тёмной темы;
- добавлены компонентные токены для вторичной кнопки;
- реализован компактный режим через переопределение компонентных токенов.

### 2. Темы
- реализованы три режима: `auto`, `light`, `dark`;
- `auto` не задаёт `data-theme`, поэтому работает через `prefers-color-scheme`;
- ручной выбор `light` и `dark` задаётся через `data-theme`;
- выбранная тема сохраняется в `localStorage` с ключом `atlas-theme`.

### 3. Кнопки
Реализованы:
- `primary`;
- `secondary`;
- `ghost`;
- `hover`;
- `active`;
- `focus-visible` используется из базового правила;
- `disabled`.

### 4. Поля
Добавлена общая стилизация `.input` и `.select`:
- высота и отступы через токены;
- placeholder;
- focus;
- disabled;
- `aria-invalid="true"`.

### 5. Уведомления
Реализованы варианты:
- info;
- success;
- error;
- warning.

Для warning добавлены текстовая роль, фоновая роль и символ, поэтому статус определяется не только цветом.

### 6. Компактная плотность
Добавлен переключатель «Плотность»:
- обычная;
- компактная.

Компактный режим меняет пять и более компонентных токенов: высоту кнопок, высоту контролов, горизонтальные отступы кнопок и полей, расстояние между компонентами и внутренний отступ уведомлений. Настройка сохраняется отдельно под ключом `atlas-density`.
